# Sledge Moscow premium site V1

Статический прототип сайта Федерации хоккея-следж города Москвы.

## Публикация на GitHub Pages

1. Создайте новый репозиторий.
2. Загрузите все файлы из архива в корень репозитория.
3. Settings -> Pages -> Deploy from a branch.
4. Branch: main, folder: /root.
5. После утверждения дизайна можно подключить основной домен.

Контент прототипа основан на действующем публичном сайте Федерации и ранее подготовленной стратегии развития. Перед финальным переносом домена рекомендуется согласовать все формулировки и изображения.
