# Sledge Moscow full site V2

Полноценная многостраничная версия сайта для GitHub Pages.

Страницы:
- index.html
- federation.html
- development.html
- news.html
- news/*.html
- history.html
- contacts.html

Важно: часть оригинальных фотографий руководства и исторических материалов в V2 подключена по прямым URL с действующего сайта. Для окончательного отключения старого сайта эти изображения нужно локализовать в репозитории. Оптимальный способ - получить ZIP/backup WordPress или папку wp-content/uploads.
